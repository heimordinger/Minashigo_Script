# Minashigo_Script

一个基于 Python 的自动化脚本项目，支持浏览器自动化、图像识别匹配、OCR 以及多任务流程控制，主要用于游戏/网页自动化操作。

---

## 📌 项目特点

- 🧠 图像识别驱动自动点击（OpenCV 模板匹配）
- 🌐 浏览器自动化控制（自定义 Browser 封装）
- 🧾 OCR 文字识别支持
- ⚙️ 多任务调度系统（Task Controller）
- 🖥 GUI 可视化界面（PySide6）
- 📦 模块化设计，易扩展
- 📥 模型资源支持 GitHub Releases 自动下载

---

## 📁 项目结构
backend/ 核心逻辑（浏览器 / OCR / matcher）
core/ 配置、路径、状态管理
controller/ 任务调度系统
gui/ 图形界面
models/ AI/OCR模型资源（需下载）
scripts/ 自动化脚本
assets/ 图片资源
