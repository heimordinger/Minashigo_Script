目标：
完成游戏的每日日常，日常分为四部分：房间领体力，竞技场，爬塔，每日关卡
辅助步骤：①返回到主界面，②返回到出击

场景描述：
- 主界面：
出击.png：前往出击的按钮，点击之后进入一段loading过程后进入出击界面，期间可能会有网络波动一类的问题。
rank.png：主界面上的玩家等级图标，可作为主界面的标识图
room.png：进入房间界面的按钮，主界面和出击界面都可以点击。点击之后经过短暂loading过程之后进入房间界面
出击.png：进入出击界面的按钮，主界面和出击界面都可以点击。点击之后经过短暂loading过程之后进入出击界面
home.png：在非战斗（包括战斗结算）界面都会出现的按钮，点击后返回到主界面
room_ap上限.png：AP达到上限时短暂显示的提示气泡，出现这个表示奖励无法领取，直接任务结束即可
解释：游戏主界面，上面有进入房间的按钮，进入出击的按钮，进入商店的按钮

-出击：
出击_logo.png：出击界面的左上角logo，可以作为出击界面的标识图
jjc.png：出击界面上的进入竞技场的按钮，点击之后短暂延迟后进入竞技场界面
ta.png：出击界面上的进入塔的按钮，点击之后短暂延迟后进入塔界面
meiri.png：出击界面上的进入每日关卡的按钮，点击之后短暂延迟后进入每日关卡界面
解释；出击界面，可以选关，可以进入竞技场，塔，每日关卡

-房间：
room_logo.png：房间的左上角logo，可作为房间的标识图
room_收取奖励.png：房间里的收取奖励按钮，点击这个按钮就可以完成奖励领取
room_ok.png：点击领取按钮之后弹出的确认窗口上的ok按钮，点击之后关闭窗口，可作为房间奖励确认窗口的标识图
房间界面，里面可以领取一定量的体力。领取通过一个按钮（room_收取奖励.png）领取，点击领取后短暂加载弹出确认界面，点击上面的ok关闭窗口。

-竞技场：
jjc_logo.png：竞技场的左上角logo，可作为竞技场的标识图
jjc_刷新.png：竞技场的刷新按钮，教程中不需要刷新，对该图点击偏移(-20,0）即可提高倍率
jjc_倍率.png：竞技场满倍率的按钮状态图，把倍率点到该图出现即可。如何？点击倍率如上一条所属。需要注意的是游戏有点击波纹样式，所以如果连续点击频率过高可能会因为波纹样式导致无法识别出来，所以点击延迟至少0.3s
jjc_段位.png：点击之后进入队伍编队界面，一般挑y值最大的点击
jjc_出击.png：竞技场队伍编队界面的出击按钮，点击之后过程loading进入战斗，可作为该界面的标识图
jjc_结算.png：竞技场战斗结算的标识图，位于游戏左上角，这时候随机点击其右下角位置即可退出结算
jjc_ok.png：段位升级奖励窗口上的ok按钮，点击之后关闭奖励窗口
jjc_end.png：挑战次数耗尽标识图，如果出现表示竞技场已打完。匹配度要高，建议0.99

-塔：
ta_logo.png：塔的左上角标识图，在塔里塔外都有
ta_cishu.png：塔挑战次数耗尽时的图片，如果出现该图片则表示没有挑战机会，任务可以结束了
ta_biancheng.png：塔选择界面上的一个按钮，对其偏移在(0,-120)-(30,-150)范围内可以切换塔的难度。切换难度时有切换动画，大概0.1s
ta_nandu.png：塔的目标难度，出现该难度时则切换完成。点击会出现确认框，确认框确认后进入塔内
ta_tiaozhan.png：进塔确认框上的确认按钮，点击短暂延迟进入塔内。可作为确认框的标识图
ta_chuji.png：进入塔后关卡的出击按钮。点击之后进入出击界面。auto模式下也会出现，如果auto模式下点击会打断auto模式。
ta_auto1.png：塔出击界面上的一个auto模式关闭样式的按钮，点击之后切换启动。
ta_auto2.png：塔出击界面上的一个auto模式启动样式的按钮，点击之后切换关闭。
ta_chuji_chuji.png：塔出击界面上的一个出击按钮，点击之后开始挑战，如果已经启用auto模式，后续挑战自动挑战。
ta_jiangli.png：塔奖励窗口的标识图
ta_ok.png：塔奖励窗口上的ok按钮，点击之后关闭奖励窗口

-每日关卡：
meiri_logo.png：每日关卡选关界面的标识图，仅在选关界面上会有，会被skip窗口遮住
meiri_skip.png：每日关卡选关界面上一键扫荡的按钮，点击之后弹出skip窗口
meiri_skip_skip.png：skip窗口上的一个确认按钮，点击之后开始一键扫荡。扫荡过程只是一段普通的动画。
meiri_ok.png：扫荡完成之后的ok按钮，点击之后则关闭窗口

任务流程描述：
（a）返回主界面
只要确保现在不是在战斗界面或者战斗结算界面，点击home.png即可回到游戏主界面，出现标识图则表示已完成

（b）返回出击界面
检查是否有出击.png，没有则执行返回主界面（a）然后重新识别，有则继续下一步，没有说明还没回到主界面 -> 点击出击.png -> 出现标识图，完成

（1）房间领体力：
回到主界面a -> 点击room.png ->检查有没有room_收取奖励.png，没有则任务完成，有则继续 -> 点击room_收取奖励.png -> 上一步点击后1.5s内关注是否出现room_收取奖励.png，如果出现则任务结束，没有则继续 -> 短暂等待奖励窗口弹出 -> 点击奖励窗口上的ok按钮 -> 上一步结束1s之后如果还有ok，那么就再点一次 -> 完成

（2）竞技场：
回到出击界面b -> 点击竞技场按钮jjc.png进入竞技场 -> 检查是否有jjc_end.png，有则已经打完不用继续了 -> 刷新倍率到满倍率 ->  点击y最大的jjc_段位.png进入编队界面 -> 点击编队界面上的出击按钮 -> 战斗结束后进入战斗结算 -> (如果提高了段位会弹出一个奖励窗口，点击上面的ok即可，期间jjc_结算.png不可匹配) -> 匹配jjc_结算.png，匹配到后随机点击游戏位置退出 -> 回到竞技场，检查是否有jjc_end.png，没有则回到[点击y最大的jjc_段位.png进入编队界面]这一步，有则任务完成

（3）爬塔：
回到出击界面b ->  点击塔按钮ta.png进入选塔难度界面 -> 检查ta_cishu.png判断次数是否耗尽，耗尽则结束，否则继续 -> 调整塔难度到目标难度ta_nandu.png并点击进入 -> 在塔里面点击出击按钮进入塔的出击界面 -> 出击界面里把auto启用 -> 点击出击界面的出击按钮进入auto自动流程 -> 某一帧持续吃了5秒且有塔奖励窗口的标识图则表示auto已经完毕，点击上面的ok按钮，之后短暂延迟回到选塔难度界面 -> 检查ta_cishu.png判断次数是否耗尽，耗尽则结束，否则回到[调整塔难度到目标难度ta_nandu.png并点击进入]这一步骤

（4）每日关卡：
回到出击界面b -> 点击每日关卡按钮meiri.png进入每日关卡界面 -> 点击一键扫荡按钮 -> 点击确认扫按钮 ->扫荡完成后点击ok按钮 -> 结束
