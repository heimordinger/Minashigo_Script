目标：
完成日常（房间领体力 → 竞技场 → 爬塔 → 每日关卡 → 领取礼物）

辅助步骤（任务中可用 @名称 引用）：
（a）返回主界面
  - 匹配 rank.png → 已在主界面则结束
  - 过场则 passive 等待（日志 [过场] 导航→主界面）
  - 可见 home 且冷却 15s 后点击 home.png，等待 rank
  - 最长 120s
（b）返回出击界面
  - 匹配 出击_logo.png → 已在出击界面则结束
  - 标识未命中：尝试点击 出击.png；成功进入出击界面则结束（不必先回主界面）
  - 过场则 passive 等待（日志 [过场] 导航→出击界面）
  - 不在主界面：冷却 15s 后点击 home，再回到上一步逻辑
  - 最长 120s
（c）打开菜单
  - 匹配menu_logo.png是否存在，已存在说明已经打开菜单直接结束该任务
  - 点击menu.png，如果失败了说明正在战斗中，直接返回失败

任务流程：
（1）房间领体力
  - 尝试点击 room.png 进入房间；成功则跳过回主界面
  - 否则 @返回主界面  （引用：@返回主界面）
  - 点击 room.png 进入房间（若上步未进入）
  - 等待 room_logo；失败回退「回主界面」
  - 若 room_ap上限 → 结束
  - 若无 room_收取奖励 → 结束
  - 若有 room_ok 先关完
  - 循环：点 room_收取奖励 → 等 1.5s → 有 room_ok 则关完并结束；无 ok 累计 3 次则结束
  - 中途见 room_ap上限 → 结束
（2）竞技场
  - @返回出击界面 → 点 jjc.png 进竞技场（等待 jjc_logo）  （引用：@返回出击界面）
  - 循环（最多 20 轮）：
  - jjc_end → 竞技场结束
  - 刷新倍率至 jjc_倍率（jjc_刷新 偏移 -200,0，点击间隔 ≥0.3s）
  - 点 x 最大 jjc_段位 → 等 jjc_出击 → 点出击（含 @出击限制 处理）→ 等战斗结束（最长 480s）
  - 结算处理（最长 180s）：
  - · 有 jjc_结算 → 随机点结算区
  - · 有 jjc_touch → 点 Touch 条
  - · 有 jjc_ok → 点 OK（含段位提升；jjc_ok 优先于 jjc_rankup 标题判断）
  - · 仅有 jjc_rankup 标题 → 等 OK 出现
  - · 回到列表（jjc_logo + jjc_段位，且无 jjc_出击）→ 本轮结束
  - 失败回退「进入竞技场」
（3）爬塔
  - @返回出击界面 → 点 ta.png（最多 3 次 × 等 2s 等 ta_logo）  （引用：@返回出击界面）
  - 循环（最多 20 轮）：
  - ta_cishu → 爬塔结束（直接结束，不做其它 UI 排除）
  - 若已在塔内（ta_chuji 且无选难度 UI）→ 跳过选难度
  - 否则：ta_biancheng 偏移切到 ta_nandu → 点 ta_nandu → 可选 ta_tiaozhan → 等 ta_chuji
  - 点 ta_chuji 进出击界面 → 开 AUTO（ta_auto1→亮蓝态，有动画延迟）→ 点出撃（ta_chuji_chuji*，含 @出击限制）
  - AUTO 运行 passive 等待（最长 480s）：
  - · ta_auto_banner 近期 10s 内出现 → 不点奖励
  - · 中间层奖励约 4s 自动关闭，不点
  - · 最终关：横幅消失 ≥6s 且奖励框稳定 ≥3s → 点 ta_ok
  - 失败回退「进入选塔」
（4）每日关卡
  - @返回出击界面 → 点 meiri.png（最多 3 次 × 等 2s 等 meiri_logo.png）  （引用：@返回出击界面）
  - 点击meiri_skip.png直到出现meiri_skip_title.png
  - 循环点击meiri_skip_skip.png，3-5s间隔循环点击直至没有。循环条件是meiri_skip_title.png存在。期间如果出现了meiri_skip_attked.png，那么直接跳进下一步
  - 点击meiri_ok.png直到消失时任务结束
（5）领取礼物
  - 匹配gift_logo.png判断是否在礼物界面，匹配成功则跳到第三步
  - 执行@打开菜单，短时间循环点击menu_gift.png直到没有  （引用：@打开菜单）
  - 点击gift_claim.png
  - 点击gift_ok.png直到没有时任务完成
（6）任务奖励领取
  - 匹配task_logo.png判断是否在任务页面，匹配成功则跳到第三步
  - @返回主界面，点击 task.png 直到没有  （引用：@返回主界面）
  - 循环：见 task_end（颜色校验）则结束；否则点 task_claim → 点 task_ok 直到消失，再继续直到 end
  - 入口 do_work：房间领体力 → 竞技场 → 爬塔 → 每日关卡 → 领取礼物 → 任务奖励领取；异常/正常结束均保存停帧。

特殊规则：
- 出击限制（通用）：jjc_出击、塔出撃等点击后若见 出击限制 → 点 出击限制_出击
- jjc_ok 模板勿裁入角色背景，否则换号阵容可能匹配失败
- jjc_rankup 用标题条识别，不用 RANK UP 闪字；需排除 FANZA 顶栏误匹配
- 塔 AUTO：ta_auto1/2 用颜色校验区分灰/蓝；出撃前需 settle 延迟避免 GUI 丢点击
- ta_cishu 出现即次数耗尽，爬塔任务直接成功结束
