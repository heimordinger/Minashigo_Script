# 窗口缩放与识图定标（待落地 → 已落地）

记录日期：2026-09-12  
状态：**已落地**（自动定标 + 缓存 + 尺寸哨兵；`match_ref` 仅可选快路径）

---

## 目标

- **不限制**用户素材裁切分辨率  
- **不限制**模拟器/窗口客户区尺寸与宽高比  
- 窗口缩放导致模板相对尺度变化时，匹配仍稳定  
- 点击坐标保持「截图像素 = 客户区点击坐标」

---

## 实现要点

1. `backend/matcher/scale_calibrate.py`：对数粗搜 + 细搜定标；缓存 key=`template|WxH|mode`  
2. 窄带 `s*×[0.97,1.0,1.03]`；连续 3 次未达阈值 → 作废并重定标  
3. `UserWindow`：帧尺寸变化 → `invalidate_vision_state()`（尺度缓存 / hotspot / 轮询缓存）  
4. `match_ref.json`：**可选**；有则跳过定标；无强制比例  
5. `adaptive_match` 统一解析尺度（浏览器/窗口共用）
