脚本说明编辑器（隔离目录）
========================

与主 GUI / ScriptGenerator 解耦，本目录自包含：

  model.py     结构化「脚本说明」模型与校验/导出
  editor.py    PySide6 编辑器界面
  drafts/      本地自动草稿（已 gitignore）

启动:
  python/python311/Scripts/python.exe -m script_spec

主窗口右下角「脚本说明」打开本编辑器（关闭仅隐藏，内容保留）；也可继续用 python -m script_spec 单独打开。
尚未接入脚本生成管线（导出文本后仍需自行贴到生成器）。
